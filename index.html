/02

Multi-Label Tweet Emotion Classification

A comparative study of four modelling paradigms for 11-class multi-label emotion detection on tweets — from a traditional encoder head to fine-tuned and instruction-tuned LLMs and zero-shot GPT-4.1 — spanning the full spectrum of modern NLP.

  • Problem framing. 11-class multi-label emotion detection, where a single tweet can carry several emotions at once — evaluated across four distinct approaches to contrast traditional ML, fine-tuned LLMs, and prompt-based inference.
  • Encoder baseline. Fine-tuned a transformer encoder with a multi-label classification head as the traditional benchmark to measure the LLM approaches against.
  • Fine-tuned generative LLM. Parameter-efficiently fine-tuned Google's Gemma-2-2B with PEFT / LoRA on Google Colab, then published the trained adapters to the HuggingFace Hub.
  • Instruction-tuned + LoRA. Adapted an instruction-tuned model with LoRA adapters for the same multi-label objective, isolating the effect of instruction tuning.
  • Zero-shot GPT-4.1. Engineered few-shot prompts with constrained JSON decoding so the API returns clean, directly parseable multi-label output with no post-processing.
  • Production inference. Served the fine-tuned adapters through vLLM with constrained JSON output for reliable, structured, production-ready predictions.
  • Experiment tracking. Logged every run and model variant in Weights & Biases for full reproducibility and side-by-side performance comparison.

/03

SBA Loan Default Classification

A production-oriented classifier predicting Small Business Administration loan defaults, built with interpretability and class imbalance front-of-mind, and wrapped in a modular batch-scoring pipeline.

  • Objective. Predict whether an SBA-guaranteed loan will default — a classic imbalanced binary classification problem with real cost asymmetry between false alarms and missed defaults.
  • Modelling stack. Built in Python with Scikit-Learn and H2O-3, using pandas for data preparation and feature work.
  • Interpretability. Applied Weight-of-Evidence (WOE) encoding and deliberate feature engineering so outputs map to explainable, risk-oriented signals rather than black-box scores — important for lending decisions.
  • Handling imbalance. Tuned classification thresholds rather than defaulting to 0.5, balancing precision and recall against the cost of an undetected default.
  • Productionisation. Engineered an automated scoring pipeline with modular functions, structured for repeatable, production-ready batch predictions.
